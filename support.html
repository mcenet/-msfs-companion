MSFS Companion Support

Use the Windows Bridge to connect Microsoft Flight Simulator to MSFS Companion on your iPhone or iPad.

Download Windows Bridge

Windows 10 or 11, 64-bit · Microsoft Flight Simulator 2024

Installation

  1. Download MSFSCompanionBridgeSetup.exe using the button above.
  2. Open the downloaded installer and approve the Windows administrator prompt.
  3. Complete the installation. The Bridge starts automatically.
  4. Wait until the Bridge window displays Status: Ready.

Connect your iPhone or iPad

  1. Connect the Windows PC and iPhone or iPad to the same private Wi-Fi or local network.
  2. Start Microsoft Flight Simulator and load a flight.
  3. Open MSFS Companion on the iPhone or iPad.
  4. The app should discover the Bridge automatically. If needed, use the local address shown in the Bridge window.

Windows Firewall

The installer creates an inbound Windows Firewall rule for TCP port 8081 on Private networks. It also enables local network discovery for the app.

For your security, make sure your home network is configured as Private in Windows. The installer does not open the Bridge on Public network profiles.

Troubleshooting

  • Confirm that the Bridge window says Status: Ready.
  • Confirm that both devices are connected to the same local network.
  • Disable VPN or guest-network isolation temporarily if discovery does not work.
  • Close and reopen MSFS Companion from the Windows Start menu.
  • Restart the iPhone or iPad app after the Bridge is ready.

Security notice

The current Windows installer is not digitally signed, so Windows may identify the publisher as unknown. Only download the Bridge from this official support page.
